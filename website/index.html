04 / MAKE IT YOURS

Your next adventure
is a few commands away.

Linux amd64 · UTF-8 terminal · Truecolor recommended.
The interactive app needs at least 40 × 12 cells. Wide terminals give your artwork more room.

Choose your starting point.

Install a downloaded Linux package or archive, or build from source. Choose the file matching your distribution; no project repository setup is needed.

Browse releases ↗

Release assets and checksums are listed together. Source preparation downloads verified artwork once; the built application runs offline.

Uninstall or reset saved data ↗
Build the current source / Go 1.27+
git clone https://github.com/mayanklad/pokecrt.git
cd pokecrt
go run ./tools/dataset \
  --sources tools/dataset/sources.json \
  --cache .cache/dataset \
  --mappings tools/dataset/mappings.json \
  --out . --fetch --prepare-assets --check
go build -o bin/pokecrt ./cmd/pokecrt
sh scripts/install.sh ./bin/pokecrt
pokecrt tui

Internet is needed to clone and prepare assets. Go 1.27+ is a build requirement, not a requirement for the packaged executable.

BEFORE YOU SET OFF

A few good things to know.

Does it need an internet connection?

The built app works offline: artwork and metadata are embedded in the executable. Downloading a release or preparing a source build needs internet access.

Is every Pokémon appearance available?

The catalog covers all 1,025 species. Accepted artwork covers 1,017 species with 2,669 exact assets. Some forms and appearances are unavailable. PokéCRT reports this instead of showing a different sprite. See the coverage report.

Where does my trainer progress go?

It stays in local saved files on your machine. You can create multiple trainers. Replacing the executable preserves profiles and appearance settings; complete data removal is a separate, explicit step. Read about saved paths and installation.

Can I use it without starting an adventure?

Yes. Printing and public catalog access do not need a trainer. Run pokecrt print --name charizard, or use pokecrt list to explore the public catalog.

Is this an official Pokémon product?

No. PokéCRT is an unofficial fan project. Original source code is MIT licensed; third-party code, metadata and Pokémon artwork retain their respective terms. No endorsement or rights-holder permission is claimed. Read the licensing details.
